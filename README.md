# Дэлгэрмөрөн голын тохойн өөрчлөлт

**Судалгааны газар** — Хөвсгөл аймаг, Мөрөн сум. Хашаатай залгаа тохойн хэсгийг 2011–2026 оны зурагт харьцуулна. 2026 онд хашааг голоос холдуулсан тухай ажиглалтыг хэрэглэгч өгсөн.

## Ажиллуулах

Python 3.10 ба түүнээс дээш хувилбар хэрэглэнэ. Нэмэлт сан болон интернэт шаардахгүй.

```powershell
python app.py
```

- `output/report.html` — хөтчөөр нээх тайлан. Сонгосон эх зураг, гурван график, хэмжилтийн хүснэгттэй.
- `output/reference.svg` — хөндлөн шугамууд болон сонгосон цэгүүдийг 2022 оны лавлах зураг дээр тэмдэглэсэн.
- `output/profiles.svg` — эргийн ирмэгийн X, хашааны X, тухайн үеийн зурвасын өргөнийг тус тус харуулна.
- `output/measurements.csv` — хэмжилтийн хүснэгт. Харагдахгүй буюу хэрэглээгүй хэмжилтийн нүд хоосон байна.

Хавтсуудын бүтцийг хадгална. HTML тайлан зураг болон хүснэгтийг хөрш хавтаснаас ачаална. Сонголт, тааруулалт болон хязгаарлалтыг [METHOD.md](METHOD.md) файлд дэлгэрэнгүй тайлбарласан.

## Өгөгдөл ба тооцоо

`images/` хавтаст хэрэглэгчийн өгсөн Google хиймэл дагуулын сонгосон дэлгэцийн зураг бий. Он ба сарыг хэрэглэгчийн өгсөн тэмдэглэгээгээр авсан. `data/observations.json` файлд лавлах кадр, ижил Y байрлалтай хөндлөн шугамууд, огноо бүрийн эрэг ба хашааны тэмдэглэсэн X байрлал байна.

Хэмжилтийн зургуудыг 2022 оны лавлах кадрт шугаман ижил төстэй хувиргалтаар тааруулсан. JSON файлд эх кадрын тулгуур цэгүүд, эргэлт ба масштабын коэффициент, шилжилт, тулгуур цэг дээрх хамгийн их үлдэгдлийг хадгалсан. Эдгээр үлдэгдэл нь эрэг дээрх хэмжилтийн нийт алдааг тодорхойлохгүй.

Өргөнийг хашааны X байрлалаас эрэг талын харагдах ус газрын заагийн X байрлалыг хасаж тооцов. Пикселийн координат баруун тийш өсдөг. Хоёр цэгийн аль нэг нь тодорхойгүй эсвэл дараалал нь зөрсөн бол өргөнийг хоосон үлдээнэ. Графикт огноог ажиглалтын дарааллаар жигд зайтай байрлуулсан.

## Тайлбарлах хүрээ

- Өргөн болон X байрлал нь лавлах зургийн пикселээр илэрхийлэгдсэн. Баталгаатай масштаб, координатын мэдээлэлтэй эх зургаар метрийн хэмжилт хийнэ.
- Зургийн огноо, усны түвшин, мөс, сүүдэр, ирмэгийг тэмдэглэх шийдвэр болон зураг тааруулах алдаа нь харьцуулалтад нөлөөлнө.
- 2021 оны есдүгээр сарын өндөр устай мэт кадрыг ус хашаанд хэр ойртсоныг тайлбарлахад ашиглана. Ийм үед усны зах эргийн дээд ирмэгийг төлөөлөхгүй.
- 2026 оны хашааны X байрлал өмнөх үеийн хашаанаас тусдаа хэмжигдэхүүн. Гурван огтлолд өмнөх гол талын хашаатай дүйцэх мөр танигдаагүй тул 2026 оны өргөнийг тооцоогүй.
